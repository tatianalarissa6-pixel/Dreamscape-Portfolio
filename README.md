# Welcome to My World — Larissa De Souza

Interactive interior design portfolio.

## Put it online (GitHub Pages)
1. Upload everything in this folder (`index.html` and the `assets` folder) to the root of your GitHub repository.
2. In the repository, go to **Settings → Pages**, set the source to the `main` branch and the `/ (root)` folder, and save.
3. After a minute, the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Where things live
- `index.html` — the whole site (scenes, worlds, Express viewer).
- `assets/w1`, `assets/w2`, `assets/w3` — images for each world.
- `assets/express` — one image per portfolio page for the Express click-through.

To change a world's text or images, search `index.html` for `const WORLDS` — each world's steps are listed there in plain text.
